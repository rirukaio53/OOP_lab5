# Лабораторна робота №5 
Тема: Наслідування та поліморфізм

Мета: Ознайомлення з механізмом наслідування та принципом
поліморфізму. Використання механізму наслідування та
принципу поліморфізму в мові Java. Здобуття навичок у
використанні механізму наслідування та принципу
поліморфізму.

#  Завдання:
Визначити ієрархію електроприладів. Увімкнути деякі електроприлади в розетку. Підрахувати споживану
потужність. Провести сортування приладів у квартирі на
основі потужності. Знайти прилад у квартирі, що відповідає заданому діапазону електромагнітного
випромінювання.

Мова виконання: Java
